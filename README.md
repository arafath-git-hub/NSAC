
# ABANDONED BUT NOT FORGOTTEN
### The Silent Relics of Space Exploration

An immersive, cinematic website exploring the forgotten machines, abandoned equipment, and scientific relics left behind during humanity's exploration of the Moon and Mars.

---

## About The Project

Beyond Earth, humanity has left behind more than footprints.

From lunar landing equipment to robotic explorers on Mars, these forgotten objects tell the story of human curiosity, scientific discovery, and space exploration.

**Abandoned But Not Forgotten** is a storytelling website that brings these silent relics back into the spotlight.

## How To Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website.

## Deployment

This project can be hosted for free using **GitHub Pages**.

1. Upload all project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Click **Save**.

Your website will be published using the GitHub Pages URL shown in the Pages settings.
